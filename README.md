# Ignatius Sihotang — Portfolio

Modern personal portfolio built with Vite, HTML, CSS, and JavaScript.

## Run locally

```bash
npm install
npm run dev
```

Open the local Vite URL shown in the terminal.

## Pages

- `/` — main portfolio
- `/projects/iot-ids/` — IoT IDS case study

## Before publishing

- Replace placeholder Email, LinkedIn, and GitHub URLs.
- Add `public/assets/profile.jpg` if a profile photo is desired.
- Add the final CV as `public/assets/cv.pdf` and wire the download button.
- Replace the IDS demo placeholder with actual PyQt6 screenshots.
- Add final validated experiment numbers before publishing them publicly.


## IDS results
The case study includes the supplied mean K-Fold cross-validation accuracy results for Decision Tree (74.59%), KNN (63.19%), Naive Bayes (39.83%), Random Forest default (78.84%), and tuned Random Forest (79.06%).
